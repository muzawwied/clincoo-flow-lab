# Clincoo Flow Lab

Repo testing Clincoo untuk demo visual berbasis code (bukan gambar/video):

1. **Alur Permintaan** — diagram SVG animasi: garis digambar saat load, titik mengalir sepanjang jalur, cabang ke layanan (Chat AI / Editor Kode / Deploy), konvergen ke hasil.

Style: Clincoo (font Inter, Tailwind, aksen hijau minimalis).

Deploy: upload langsung ke project pages `clincoo-flow-lab`, domain testing `flow.clincoo.biz.id`.
